# Plan index

Every Markdown plan directly in `docs/plans/` is listed here once. Evidence for a
plan lives under [`evidence/`](evidence/).

**Real status** comes from counting the checklist boxes (`- [x]` checked and
`- [ ]` open) in each file, plus the corrections recorded in
[`2026-10-10-repo-docs-reorganization.md`](2026-10-10-repo-docs-reorganization.md)
(Etapa 6). It is not copied from the file header. When the two disagree, the
**Note** column says why.

| Real status | Meaning |
| --- | --- |
| completed | Every applicable box is checked, or the open boxes are explained in the note. |
| in progress | Work has started and applicable boxes are still open. |
| proposed | Nothing is checked yet. |
| no checklist | The file has no checklist boxes: a record, notes, a baseline, or an older plan format. |
