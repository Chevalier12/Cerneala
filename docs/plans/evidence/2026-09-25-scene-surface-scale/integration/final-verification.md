Status: **accepted by the shared independent auditor for the automated Windows SDL scope**. This file records automated evidence, not human validation or a framework-wide pixel-parity guarantee.

## Selected contract and implementation

- `VillageGameSurface.Zoom` is a programmatic, finite-positive camera factor; its default is `1`. `ContentScale` is nullable, defaults to `null` (inherit window DPI), and accepts only finite-positive explicit values. Invalid setters throw `ArgumentOutOfRangeException` without changing either property or the current `ViewBox`. The game window sets `ContentScale="1"`; no gesture or toolbar control was added.
- The camera uses the **unchanged full-resolution** `RenderSurface2D` target extent `max(1, ceil(arranged DIP extent × root DPI scale))` and sets followed `ViewBox` coverage to `clamp(target pixels / (ContentScale × Zoom), 1, 4096)`. For inherited scale, `ContentScale` resolves to root DPI. This is app-owned camera policy, **not** a new Core `RenderSurface2D` property, a lower-resolution intermediate target, or a global UI DPI change. RenderSurface3D is untouched.
- Tiny Town source/destination cells are 16×16; the player and stress actor source/destination frames remain 32×32. Houses become 64×64 world units with a proportional 64×32 body collider. The two-cell green tree becomes 16×32, anchored to the existing lower-cell site; decoration colliders scale with art. World size stays 4096, player speed 200 world units/s, stress pitch 32 and distribution/count presets unchanged. Ground/path tile counts increase to retain their existing world-space coverage. The player's world-edge clamp uses its 32-unit actual dimensions.
- The only Core/SDL/backend *source-surface* changes for this task are test access: `InternalsVisibleTo("Cerneala.Tests.SceneVillage")` in Core and equivalent friend entries in SDL platform and GPU-backend projects. These use established native host seams for controlled DPI. Existing unrelated dirty Core/project diffs, including prior shader resources and package friend assemblies, were preserved. There is **no new Core public or protected API** and no backend production behavior edit in this task. App-local API behavior is documented in `Playground/Cerneala.SceneVillage/README.md`; asset source and hashes remain in `Assets/CREDITS.md`.
