# ComboBoxItem Class

## Definition
Namespace: `Cerneala.UI.Controls`

Assembly/Project: `Cerneala`

Source: `UI/Controls/ComboBoxItem.cs`

Represents a selectable item container generated by `ComboBox`.

```csharp
public class ComboBoxItem : ListBoxItem
```

## Examples

```csharp
using Cerneala.UI.Controls;

ComboBoxItem item = new() { Content = new TextBlock { Text = "Draft" } };
ComboBox comboBox = new();
comboBox.Items.Add(item);
```

## Remarks

`ComboBoxItem` reuses the `ListBoxItem` selection contract. Its `Item` property preserves the original item independently from the visual content presenter used by `ComboBox`.

## Properties

| Name | Description |
| --- | --- |
| `Item` | Inherited original item value represented by the container. |
| `ItemIndex` | Inherited source index. |
| `IsSelected` | Inherited selection state. |
| `Content` | Inherited displayed content. |
