# Sprite animation stage 4 verification

## Deterministic native conformance

The shared `tests/Shared/SpriteAnimationConformanceFixture.cs` runs unchanged on
WindowsDX and SDL_GPU through their existing smoke applications. The atlas is
an input asset generated by Skia; every application capture is produced by
`Window.SaveScreenshot`, never an OS screen-copy path.

```powershell
dotnet run --project tests/Cerneala.WindowsDxSmoke -c Release --no-build --no-restore -- --capture-sprite-animation benchmarks/Cerneala.Benchmarks/results/2026-09-04-sprite-animation-stage4/WindowsDx
dotnet run --project tests/Cerneala.SdlGpuSmoke -c Release --no-build --no-restore -- --mode sprite-animation --artifacts benchmarks/Cerneala.Benchmarks/results/2026-09-04-sprite-animation-stage4/SdlGpu
dotnet run --project tests/Cerneala.WindowsDxSmoke -c Release --no-build --no-restore -- --verify-sprite-animation benchmarks/Cerneala.Benchmarks/results/2026-09-04-sprite-animation-stage4/WindowsDx benchmarks/Cerneala.Benchmarks/results/2026-09-04-sprite-animation-stage4/SdlGpu benchmarks/Cerneala.Benchmarks/results/2026-09-04-sprite-animation-stage4/comparison.json
```

Both Release builds: zero warnings/errors. Both captures: exit 0.
Four samples per backend: 0, 100, 200 and 300 ms. Playback is paused between
captures; exact 100 ms pulses use the real surface's existing UI-time interface.
The native host does not select frames by waiting for wall-clock delays.
Automatic registration/lifecycle is independently covered by the stage-3 tests.

One immutable three-frame looping clip is shared by a plain reference sprite,
a tinted/flipped sprite with individual Prism, a transformed group with Prism,
and one promoted tile among 32 static cells. Aspect supplies state/definitions
and tint. Motion commits explicit opacity/rotation endpoints at sample 100;
this proves endpoint integration, not native intermediate-time interpolation.
Core tests cover Motion interpolation and cancellation/restoration. Tile rotation
also overlaps a static neighbor, exercising the promoted cell's semantic slot.

Pixel grids change between each consecutive sample for all four animated
targets. The plain reference and unchanged group restore their initial pixels
at the exact loop endpoint. Sprite/tile opacity intentionally differs from t=0
after Motion, so their final screenshots are not asserted identical to t=0.
Public collision raycast and normal UI hit testing are checked before/after
Prism attachment and at every sample. This is automated geometric verification,
not a claim of human manual validation or interactive input coverage.

`comparison.json`: all captures are 800x525 physical pixels (640x420 logical).
Maximum channel delta is 1 for every pair. Channel tolerance is the existing 3;
zero pixels exceed it, zero raster-edge allowances are consumed, and zero pixels
remain unresolved. No golden image or tolerance was changed.

The native fixture initially attempted internal recorder/counter APIs available
only to the Windows friend assembly. The SDL compilation rejected that fixture.
It now uses public state/geometry and captured pixels on both backends; no friend
assembly or public API was widened. Exact command source rectangles/scopes and
static batch reuse remain asserted by core tests and the stage-3 benchmark.

## Authorized SpinBlur investigation, 2026-09-05

- A temporary native probe omitted the Prism attachment, keeping the same
  primitives, host sizes and capture paths. WindowsDX versus SDL_GPU input
  images were identical: MAE=0, P99=0, max=0. The temporary branch was removed;
  the original catalog fixture is unchanged. Cleanup of the two probe-output
  folders under the test binary's `TestResults` and `spin-input-probe.trx` was
  rejected by the execution tool's policy; those generated outputs remain.
- `PrismGraphExecutor` allocates mipmapped WindowsDX execution surfaces;
  SDL_GPU does not allocate mipmaps for neighborhood passes. Both use linear
  samplers. The shared SpinBlur kernel formerly used implicit-derivative
  texture reads inside its spatially varying count/early-exit control flow.
- Permanent regression `PrismSpinBlurGpuTests` gives the GPU a constant red
  base level and blue sentinel lower mip levels. Normalized averaging of base
  pixels must preserve red, matching `PrismNeighborhoodMath.SampleSpin`'s
  base-resolution bilinear contract. Before the fix, the non-mipmapped control
  passed; the mipmapped case failed with maximum Vector4 error **0.78807193**
  against tolerance 0.002. `spin-mip-red.trx` is the valid RED run. Earlier
  fixture attempts had missing/incorrect graph parameters, not valid REDs;
  the final fixture uses the existing graph builder and generated defaults.
- The shared HLSL now requests explicit LOD 0 only for SpinBlur neighborhood
  reads. Other filters retain their prior implicit sampling. Shader package
  versions advance together from 56 to 57. No CPU formula, public API,
  conformance threshold, golden or LanguageServer implementation is changed.

Post-fix focused verification (`spinblur-green.trx`): 3/3 pass, no skips,
including both mip-availability cases and the original unchanged native
catalog reproduction. SpinBlur now reports **MAE=0.0011, P99=0, max=1**.
The animated sprite/tile smoke was rebuilt/recaptured on both backends and the
four fixed-time comparisons still have max channel delta 1, no over-tolerance
pixels and no raster-edge allowances. Core assembly SHA256 remains identical
to the strict API audit, so that current-state result is reused.

SDL compiler regenerated all five logical shader artifacts and verified them;
only PrismCatalog's DXIL/SPIR-V/MSL hashes changed. SDL Release build has zero
warnings/errors. The WindowsDX shader rebuild passed with **158 FX compiler
warnings**, zero errors (8m22s). It was not a warning-free shader build; warnings
include implicit-gradient/integer-divide/uninitialized-variable diagnostics in
other shader paths, which were not repaired in this scope. Native execution
on non-Windows runners was not performed.

The first post-fix solution invocation (`final-suite.log`, `final-suite/`) ran
